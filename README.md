# EXAMEN UD1 - Presupuesto de Catering

Aplicación PHP para gestionar un presupuesto de catering usando sesiones.

## Archivos
- 'datos.php': array de servicios de ejemplo.
- 'imprimir.php': muestra la tabla estática y estadísticas.
- 'gestionar.php': aplicación dinámica con sesiones, formularios, eliminación y modificación de unidades.

## Uso
1. Colocar en un servidor PHP.
2. Abrir 'imprimir.php' para ver el ejemplo estático.
3. Abrir 'gestionar.php' para la versión interactiva.
